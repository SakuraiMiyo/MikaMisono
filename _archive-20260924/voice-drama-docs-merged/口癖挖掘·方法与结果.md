> 目标：把未花的**小口头禅**（打招呼的呀吼、笑声、尾巴）系统挖一遍，
> 而不是靠印象或二手百科往上添。
>
> 建立于 2026-09-24。结论已写进知识库底本 `agent/knowledge/dialogue-corpus.md` § 4.0 口癖总表。

**结论：这轮真正的收获全部来自本地语音语料，网络侧一条也没用上。**

这不是失败——按项目自己的《资料来源与核实方法》，
中文 wiki 类站点本来就「只能当线索，不能当证据」。
而语音转写 + 剧情语料是**一等证据**。凡是两者都查不到的，就不写进知识库。

### 为什么网络侧查不到"口癖"

口癖这种东西，**百科正文里没人写**：
- 攻略 wiki 只关心数值和评价；
- 百科写的是设定和剧情梗概；
- 角色条目的"语音"小节通常只列音频文件名。

**只有把台词本身摊开数一遍才能得到。** 这也是为什么这轮的产出是一张带命中数的表，
而不是一段描述。

## 二、方法：三种挖法，按可靠度递减

### ① 定向查（最可靠）

给一张候选表，逐个数在语料里出现多少**条**。

```powershell
& $py catchphrase_lookup.py
```

好处是**能证伪**。这轮就否掉了一批：

| 候选 | 命中 | 结论 |
|---|---:|---|
| おはよう / こんにちは / こんばんは | **0 / 0 / 0** | 她不用标准寒暄 |
| はじめまして / お久しぶり | **0 / 0** | 同上 |
| さようなら / バイバイ / じゃあね / またね | **0 / 0 / 0 / 0** | 同上 |
| 早上好 / 早安 / 晚上好 / 初次见面 / 请多指教 | **0**（中文侧） | 同上 |
| ハロー | **0** | 不是她的招呼 |
| 呀吼 | **1**（`101223`） | ✅ 真的，但**是"找到老师了"**，不是"你好" |
| やっほ / やっほー | **3**（配音） | ✅ 真的 |

### ② n-gram 自动挖（用来发现没想到的）

```powershell
& $py mine_catchphrases.py 26      # 2-gram 起（会满屏语法词，参考用）
& $py catchphrase_lookup.py        # ③ 段的 3-gram 起（有用）
& $py mine_zh_habits.py            # 中文侧：句首前两字 / 句末最后两字
```

⚠️ **日文 2-gram 基本没用**——前几名全是 `って / 先生 / った / ちゃ / ない / んだ`，
那是语法不是口癖。**要从 3-gram 起挖**，或者干脆按「句首词频」看。

**中文侧收获最大的两个视图**：

| 视图 | 头部结果 |
|---|---|
| 句首前两字 | `……` 18.2% / 老师 2.9% / **啊哈 2.0%** / 啊，1.9% / 嗯，1.8% / 诶，0.9% / **哎呀 0.7%** |
| 句末最后两字 | `……` 24.4% / 了。5.0% / **呢。4.9%** / **吧？4.5%** / 吧。3.4% / 吗？3.3% / **哦。2.4%** |

> 「……开头 18.2%」这一条本身就是口癖：**她大量从沉默开始说话。**

### ③ 原句回看（必须有，否则会误判）

```powershell
& $py show_catchphrase_lines.py 呀吼 嘿嘿 啊哈哈 唔 哇
```

数字只说明"有"，看不出"怎么用"。比如 `啊哈哈` 21 次，
回看原句才发现**它主要不是"开心"，而是"盖尴尬"**：

```
[100596] 啊哈哈……我又把事情搞成这样了。
[32170]  ……真相？啊哈哈！
[33030]  啊哈哈，我说着玩而已嘛。
```

再比如 `唔` 20 次，回看才发现它是 `うーん / んー / うぅっ` 的**统一中文写法**，
是"思考 + 迟疑"的固定声，不是语气词。
