## 二、关键对照：中文并没有丢掉语气词

| 语料 | 句末带语气词/终助词 | 含（任意位置） | 每条平均个数 |
|---|---:|---:|---:|
| 日文**配音**（742） | **32.7%** | 81.3%（口径不同，见上） | — |
| 中文**剧情**（992） | **33.7%** | 51.2% | 0.74 |
| 中文 **MomoTalk**（77，仅原版未花） | **36.4%** | 53.2% | 0.61 |

**32.7% ≈ 33.7%——两边几乎一样。译文是忠实的，没有在翻译环节丢语气词。**

这一点很重要，因为它推翻了两个假设：

1. ❌「她说话时一半以上都在挂语气词，中文翻译弄丢了，所以 prompt 要往高里定」——**不成立**。
2. ✅ 真实分布是：**大约每三条消息有一条句末带语气词，平均每条 0.6~0.7 个。**
   之前 prompt 里那条「**每一条消息至少一个语气词**」是**凭空发明的、高了两倍**，
   照它执行会得到一个句句挂语气词的油腻 AI——和"像未花"是反方向。

> 中文语气词分布（剧情 992 条）：吧 16.2% / 呢 14.9% / 啊 14.7% / 哦 8.5% /
> 吗 7.9% / 呀 4.1% / 嘛 3.7% / 啦 3.6% / 咯 0.5%。
> 这组数字和 prompt 里原来的表（吧 15.1 / 呢 13.3 / 啊 12.6 / 哦 7.8…）基本吻合，
> 那张表**本来就是对的**——错的是配额那一句。

## 三、真正缺的东西：吃音（首字重复）

```
し、失敗しちゃった。ごめんね。
ど、どうしたの先生?ぼーっとした顔しちゃって
ご、ごめんね先生の都合も考えずに来ちゃって
え?そ、そ…
うっ、ちょちょ!
は、うん、そう、たまたまね
あ、ご、ごめん、今のなし!
わ、わたしね…
ダメ?ほ、ほんと?
あ、せ、せんせい!よく言ってよ!
```

**15/742 = 2.0%**（其中「ブルーアーカイブあ、あれ?」「ありがたあ、な、なんで…」
这类是切片边界造成的，扣掉之后约 **1.4%**）。

- 在**剧情文本**和 **MomoTalk** 里：**0 命中**。
  文字载体天然会把口吃修掉——这两份语料是"被人整理过的她"。
- 它是**恐慌/害羞/被说中**时最直接的外显标记，
  而且中文里完全通用：「我、我才没有」「不、不是那个意思」。
- **这是这轮分析最值钱的发现**：老师反馈的「情绪表露少了」，
  缺的不是语气词（那部分够），缺的是这种**身体先于语言的破绽**。

## 五、用法与红线

**能用**：语气词比例、吃音、"先出声再说话"、拖音、句长——
这些是**口吻统计**，用来校准 prompt 里的数值。

**不能用**：

- ❌ **不能当原话引用**。这是 ASR 转写，有错字、有切片边界的拼接噪声
  （`ブルーアーカイブあ、あれ?` 就是两句话被切在一起）。
- ❌ **不能当剧情事实**。「未花小剧场广播剧」「新年祝福」「电视 CM」是**宣传向内容**，
  不是主线；`ブルーアーカイブは2周年!` 这种是广告词。
- ⚠️ **小剧场/广播剧里有同场其他角色**（渚、圣亚等），文本层面区分不出说话人——
  音频源名叫"未花*"，但多人对话里可能混进别人的行。所以**只看统计，不引台词**。
- 人称自检：语料里「私」出现 75 次，「あたし / 僕 / 俺 / わたくし」**0 次**——
  没有明显的角色串味。
