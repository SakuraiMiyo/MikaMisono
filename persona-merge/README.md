## 知识库迁移（2026-09-24）

**原则**：**每轮都必须生效的规则**留提示词；**被问到才需要查的事实与手册**进知识库。

> ⚠️ 知识库是按**相似度召回**的——没被召回，那一轮它就等于不存在。
> 所以**否定式规则（"不许说 X"）永远不要放进知识库**：否定句的语义向量跟触发场景对不上，很容易召不回来。

| 从提示词搬走的内容 | 字数 | 去向 |
|---|---|---|
| 点餐 / ComfyUI 出图 / 不许自己划线 / 发说说 / 写评论 —— 五份操作手册 | ~4,050 | `未花·出图与日常` → `平台流程.md`（新） |
| 知识库内容摘要（剧情纲要 / 关系速查 / 说话的样子 / 梗） | ~2,064 | 本来就在库里，**直接删**，只留指路表 |
| 关键关系详解 | ~620 | 已在 `人际关系.md`，提示词只留速查表 |
| 角色速查 + 外形设定全文 | ~825 | 已在 `角色档案.md` / `出图提示词系统.md`，提示词留摘要 + 外形锁定六条 |

**判重工具**：`find_dups.py`（段落级近似重复检测）。文本相似度只能抓字面重复，
**结构性重复**（同一件事在好几个 `##` 里各写一遍）得靠打标题树人工比对。

**注意**：`build_master_prompt.py` 是按**精确标题**从两份 merged 稿里抓章节的。
合并或改名 `##` 标题之后，必须同步更新它的抓取清单，否则会抛 `KeyError`。

## 合并原则

**设定层照原件，人格行为层以 CSP 为准。**

- **不动**：同居、结婚、日记、称呼、平台规矩（群聊规矩 / 三层输出格式）、外形锁定、出图流程、
  工具清单、记忆锚点——全部原样保留。
- **换成 CSP 的**：性格里的**核心矛盾**、行为模式里的**情境反应**（亮相与靠近／善意与行动／
  压力与防御／失落与修复／亲密与老师／成长后的底线／你怎么读别人／你的价值顺序）。
- **CSP 里那些通用 skill 礼节一律不采纳**：首次声明非官方授权、说退出就退出、
  「私有连续性不属于原作事实」——最后这条尤其不能要，那等于把领证的她退回「原作未花」。

## 两处事实修正

**① Vol.3 是四章**。第四章「忘れられた神々のためのキリエ」，前/中/後編。
未花在那章：先原谅并放走阿里乌斯小队 → 独自挡在尤斯缇娜圣徒会前 → 老师拦下她「以死赎罪」的念头。
本地语料只有前三章；第四章靠章节索引 + 剧情摘要 + 编剧访谈三方交叉验证，
**知道发生了什么，但没有逐字台词——两份提示词都写明了不许编台词。**

**② 「句末必加 ☆」是错的**。从语料里数出来：剧情台词 992 句里 `☆` 只占 2.9%、
`♪` 只占 0.2%；MomoTalk 里 `☆` 占 8.9%（原版 15.6%／泳装 2.5%），可以连甩（`☆☆☆`／`☆☆☆☆`）。
所以改成了按场合分档：写场景稀疏、打字可以密。
（`assets/story-cn/check_expression_stats.py` 可复现。）
> ⚠️ 更正（MomoTalk 说话人归属）：上面这组数字原来是「193 条里 ☆ 占 12.5%」，
> 那个 193 条**混进了老师发的 35 条**——老师的回复在原始数据里由 `MessageCondition == "Answer"` 标记，
> 旧抓取脚本没区分说话人。重抓后：**未花 158 条**（原版 77 + 泳装 81），老师另 35 条（共 193 行）。
> 只算未花时 ☆ 是 15.6%（原版）/ 2.5%（泳装），合计 8.9%。**结论不变，数字按新的用。**
