## 7. 常见坑(部署时最常撞的)

| 症状 | 原因 | 解法 |
|---|---|---|
| 数据根跑到 `backend\data` | 启动方式不对(缺 `ASTRBOT_DESKTOP_CLIENT=1`) | 用 `start_backend_desktop_env.ps1` |
| 改了人格没生效 | 直改 SQLite 不刷缓存 | 永远走 `persona_api.py`;直改库要重启 |
| `json.load` 炸 UTF-8 BOM | cmd_config.json 带 BOM 是常态 | 读用 `encoding="utf-8-sig"`,写回保 BOM |
| 适配器不连 | platform[0].enable 被关 / NapCat 没跑 | 查 cmd_config `platform[0].enable=true` |
| KB 检索无结果 | Ollama 没跑 / kb_names 空 / kb_agentic_mode=true | 三处各查一遍(cmd_config `kb_names` 5 个集合) |
| 补丁脚本报"锚点命中 0 次" | AstrBot 版本不是 v4.27.3 | 停,查版本;不要手改锚点 |
| 知识库注入后她念档案腔 | 补丁 #1/#5 没打上 | verify_live_patches 必须全绿 |
| 中文输出乱码 ✗✓ | 控制台 GBK | 脚本已自带 reconfigure;手跑命令设 `$env:PYTHONIOENCODING='utf-8'` |
